### 1. What API was it asking for? Did we use any here?
Previously, the code had a **fallback to OpenRouter** (Cloud LLM API). If the local matching could not recognize a command (e.g. if you said something slightly different or if it misheard), it would automatically try to send the text to a cloud server to figure out the intent. 
* This required an **OpenRouter API Key** in `settings.ini`, which you didn't set.
* This is why it took 10+ seconds to respond and then showed an error (because there was no API key configured).
* **We have now completely removed all cloud API fallback calls.**
* All command recognition now happens **locally** and **instantly** (0ms delay) on your computer.
