Forged in Darkness & Divinity

Every single feature is built with maximum performance, fluid animations, and premium visual elegance in mind.

Real-Time Speech-to-Text

Speak naturally, and watch it transcribe in real time. Features single-click clipboard copying, clear, and direct export to Notepad (`Notepad ↗`).

Jarvis Voice Assistant

A fully integrated offline/online voice assistant mode responding to the "Hey Jarvis" wake word, wrapped in a beautiful glowing mic pill animation.

Smart Media Module

Supports Album Art colors extraction, live responsive waveforms, and custom badges for Tidal, Spotify, Amazon Music, and web browser sources.

Mini-Pill Carousel

Cycle between Clock, Calendar, Weather, and System alerts using your mouse scroll wheel, swipe navigation, or tap to expand.

Organic Physics & Fades

Transitions are powered by a dual-damping spring physics loop and custom opacity fades, generating a beautifully organic feel at 60 FPS.

Native Desktop Settings

Right-click the island to launch a beautiful settings window. Change positions, configure metrics, and tweak opacity immediately.

Command The Divine Island

Setup is extremely simple and fast. Choose your preferred installation method below.

Method 1: Direct Executable

Simply download the pre-compiled standalone version of Dynamic Island, which runs instantly with zero configuration.

1 Download DynamicIsland.exe.
2 Double-click to launch. It will automatically initialize in your system tray.
3 Right-click the island at the top of your screen to open settings and configure startup.

Method 2: Install via Windhawk

If you use Windhawk for system customizations, you can inject it directly as a system mod.

// Copy code from the Github page and paste into Windhawk mod creator
1 Open Windhawk and click "Developer Writing Mod".
2 Paste the code from window-dynamic-island.wh.cpp.
3 Click "Compile and Inject" to run it smoothly!
